## Общее описание

Разработано веб-приложение **Help Desk** — учебная система для регистрации и сопровождения обращений пользователей в службу поддержки. Проект реализован поэтапно в четырёх модулях, каждый из которых добавляет новый слой функциональности.

Приложение расположено в папке `helpdesk/`.

## Модуль 3 — «third module» (база данных и сущность заявки)

**Коммит:** `8972b4d` — 8 июня 2026, 20:21

### Что сделано

1. **Подключены зависимости для работы с БД:**
   - `spring-boot-starter-data-jpa`
   - `h2` (in-memory база данных)
2. **Настроена база данных H2** в `application.properties`:
   - in-memory БД `helpdeskdb`
   - H2 Console на `/h2-console`
   - Hibernate DDL: `create-drop`
   - отложенная инициализация данных (`defer-datasource-initialization`)
   - вывод SQL в консоль
3. **Создана JPA-сущность** `Ticket`:
   - поля: `id`, `title`, `description`, `status`, `createdAt`, `customerName`
   - аннотации `@Entity`, `@Table`, `@Column`
   - `@PrePersist` — автоматическая установка даты создания и статуса `NEW`
4. **Создан enum** `TicketStatus`:
   - `NEW` — новая заявка
   - `IN_PROGRESS` — в работе
   - `RESOLVED` — решена
5. **Создан репозиторий** `TicketRepository`:
   - наследует `JpaRepository<Ticket, Long>`
   - методы: `findAllByOrderByCreatedAtDesc()`, `findByStatus()`
6. **Создан контроллер** `TicketController`:
   - `GET /tickets` — отображение списка заявок
7. **Добавлен шаблон** `tickets.html` — таблица заявок с ID, пользователем, темой, статусом и датой.
8. **Добавлены тестовые данные** в `data.sql` — 4 заявки с разными статусами.
9. **Обновлена навигация** — добавлен пункт «Заявки».

## Архитектура приложения

Приложение построено по классической многослойной архитектуре Spring MVC:

```
Браузер
   ↓
Controller (PageController, TicketController, HelloController)
   ↓
Service (TicketService / TicketServiceImpl)
   ↓
Repository (TicketRepository)
   ↓
База данных H2 (таблица tickets)
```

**Применённые принципы ООП и паттерны:**

| Принцип / паттерн | Где применён |
|---|---|
| **Инкапсуляция** | Поля сущности `Ticket` с геттерами/сеттерами |
| **Абстракция** | Интерфейс `TicketService` отделяет контракт от реализации |
| **Enum** | `TicketStatus` — типобезопасные статусы заявок |
| **DTO** | `TicketCreateDto` — отдельный объект для данных формы |
| **Repository** | `TicketRepository` — абстракция доступа к данным |
| **Dependency Injection** | Конструкторная инъекция в контроллерах и сервисе |
| **Separation of Concerns** | Разделение на controller / service / repository / model / dto |
